# Application « notion like »

Cet emplacement accueillera le **code de l'application « notion like »** développée avec les agents pendant la semaine AI SDLC (surtout le jour 5, Code).

> Ce dossier ne contient volontairement **aucun code** pour l'instant. Il sera alimenté par l'équipe qui développe l'application.

## Ce qui doit aller ici

- Le code source de l'application (front, back, tests), à la racine de ce dossier ou dans des sous-dossiers (`src/`, `tests/`…).
- Les fichiers de configuration propres à l'application (gestionnaire de paquets, linter, CI locale).
- Un fichier `.env.example` listant les variables d'environnement attendues, **sans aucune valeur secrète**.

Ce qui n'a rien à faire ici : les supports d'ateliers (`atelier-*`), le guide (`guide/`), le kit d'agents (`kit/`) et tout identifiant ou secret.

## Comment la lancer

À compléter par l'équipe de l'application dès que le code existe :

| Étape | Commande |
|-------|----------|
| Prérequis (versions d'outils) | _à renseigner_ |
| Installation des dépendances | _à renseigner_ |
| Lancement en développement | _à renseigner_ |
| Tests | _à renseigner_ |
