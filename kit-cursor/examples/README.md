# Exemples pivots

Les fichiers `*.yaml` ici (ex. `user-story.yaml` avec la clé `AISDLC-456`) servent
de **cas fictif cohérent** pour valider les schémas et faire une démo hors live.

En atelier réel (Specify → Prototype) :

- les stories vivent dans **Jira projet AS2** ;
- clés **`AS2-*`** ;
- label **`prete`** pour entrer en Prototype ;
- pas d’export YAML fourni par Specify — Flow Mapper normalise depuis Jira.
