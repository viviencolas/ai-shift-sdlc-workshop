# Definition of Done · la story est terminée

S'applique après la réalisation (jours suivants). La story doit
dès maintenant contenir ce qu'il faut pour pouvoir la vérifier.

| #  | Une US terminée…                                                                  |
|----|-----------------------------------------------------------------------------------|
| 01 | A tous ses critères d'acceptation vérifiés (chaque scénario constaté).           |
| 02 | A son plan de taggage en place : événements nommés et leurs propriétés            |
|    | (ex. « commentaire assigné », « fil résolu »).                                    |
| 03 | A son indicateur de succès visible dans l'outil d'analyse.                        |
| 04 | A été revue et acceptée par le PO.                                                |

Conséquence pour le J2 : chaque story publiée contient une section
« Plan de taggage » (événement, déclencheur, propriétés) et le nom
de son indicateur de succès.
